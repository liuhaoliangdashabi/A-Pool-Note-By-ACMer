## 裴蜀定理
a,b为不全为0的整数，存在整数使**ax+by=gcd(a,b)**(辗转相除法逆着退回去)
另一理解：ax、by有差值且以当时正数，但要求最小的整数，辗转相除下去
### 推论
1. a,b不全为0，**a和b互质**，当且仅有x、y使**ax+by=1**(gcd(x,y))
2. a,b不全为0，ax+by=c有解，则**c必为gcd的整数倍**
   （反例举证，如果不是，新式-旧式肯定会出现更小的数，说明gcd求错了）
## 扩展欧几里得——得到一组解
理论O(log min(a,b))
保证a、b没有负数，可以算到gcd及其中一个特解x、y——逆着退回去，最后为`1*gcd+0*0`
$$
d=xa+yb
=x*b0+y*(a0-?*b0)
=x0*a0+y0*b0
$$
其中$x0=y$，`y0=x - y*(a0/b0)`
```python
def exgcd(a,b):
	if b==0:return a,1,0 # 也可不这么写，只不过全局变量定义
	else:
		gcd,x,y=exgcd(a,b)
		px=x;py=y
		x=py;y=px-py*(a/b);
		return gcd,x,y
```

### exgcd求逆元
$$
	a*(a的逆元)%mod=1
=> a*(a的逆元)=?*mod+1
=> a*(a的逆元)+by=1
$$
注意：特解**可能为负数**，可(x%mod+mod)%mod处理

区分两种求逆元
- 费马小定理：mod必须为质数
- exgcd：a、b互质
