## 如题：最大公约数与最小公倍数
辗转相除法求最大公约数：
```python
while b!=0: # 这是个较小数
	a,b=b,a%b

def gcd(a,b):
	return b==0?a:gcd(b,a%b)
```

最小公倍数=`a/gcd(a,b)*b`
为什么：因为a`*`b=(a独`*`gcd`*`b独`*`gcd)，最大公约数乘了两次


## 同余原理
1. 被余数可能较大，long long装不下
2. 多个中间值位数不确定，计算不再是O(1)
**每个中间结果保留一个余数，最后结果能对上**
> 加法同余原理:`((a+b)+(c+d))%m=((a+b)%m+(c+d)%m)%m`外层防超过m
> 减法同余原理:`((a+b)-(c+d))%m=((a+b)%m-(c+d)%m +m )%m`减m防止负数(题目一般只要正数)
> 乘法同余原理:同上
