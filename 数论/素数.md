## 埃氏筛
碰到一个素数，把`素数*i`都标为false（这个数%素数`==0`，必定是合数）
```python
primes=[]
is_prime=[True]*(mx+1)
for i in range(2,mx+1):
	if is_prime[i]:
		is_prime[i]=True # 一路往后推，合数都没了，留下质数
		for j in range(i*i,mx+1,i): # 小优化:2*3标记过，不必标3*2，i*i开始
			is_prime[j]=False 
			# 这里可以避免溢出：枚举倍数，这里就是is_prime[i*j]=False
```
时间复杂度：`∑ mx/p=mx(1/2+1/3+...+1/n)=O(n loglogn)`

## 欧拉筛（线性筛）
埃氏筛有个问题：一个合数可能被划很多次
这里取余是时间消耗点，适用于数据范围更大
解决：**每个数**(合数也要)乘以小于/等于它的质数
	  仅乘到**它的最小质因子**就完事
```python
for i in range(2,mx):
	if is_prime[i]:primes.append(i)
	for p in primes:
	if p*i>mx:break # 超过范围，后面不用浪费时间
	is_prime[p*i]=False
	if i%p==0:break # 最小质因子已经处理
```
